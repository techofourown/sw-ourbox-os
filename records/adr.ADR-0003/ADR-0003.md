# ADR-0003

Tenant is the canonical top-level data boundary.

Tenant context is derived from the leftmost DNS label of the full host.

Tenant-origin patterns:
- local-only mode: `http://<tenant_id>.local/...`
- public custom-domain mode: `https://<tenant_id>.<box-host>/...`

Path identifies app in both modes.
