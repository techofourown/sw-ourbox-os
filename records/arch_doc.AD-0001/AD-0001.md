## Architectural constraints
- Local-only mode is HTTP-only.
- Public custom-domain mode is HTTPS/TLS.
- Full host carries tenant context in both modes.
- `tenant_id` is derived from the leftmost DNS label of the full host.
- Path identifies app.
- Full installable-PWA posture is public custom-domain mode.

## Core invariants
Tenant-origin patterns:
- `http://<tenant_id>.local/<app_slug>`
- `https://<tenant_id>.<box-host>/<app_slug>`

Replication endpoint patterns:
- `http://<tenant_id>.local/db`
- `https://<tenant_id>.<box-host>/db`

`http://bob.local` and `https://bob.<box-host>` are different origins and therefore different local tenant replicas.
